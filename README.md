\# CXR-AI Assist



Production-grade clinical decision support system for chest X-ray triage.



\## Features

\- Multi-label pathology detection (5 conditions)

\- Automated Cardiothoracic Ratio calculation

\- Grad-CAM explainability heatmaps

\- DICOM file support

\- HIPAA-style audit logging



\## Tech Stack

\- Backend: FastAPI, SQLAlchemy, ONNX Runtime

\- Frontend: React, TypeScript, Tailwind CSS

\- ML: PyTorch, torchvision, pytorch-grad-cam

\- Infra: Docker, PostgreSQL, Redis, MinIO, Nginx



\## Quick Start

docker-compose -f docker/docker-compose.yml up -d
